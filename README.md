# ChatGPT NixOS Workbench

**v0.3.2 · автономный мастер проектирования NixOS-конфигурации**

Откройте [ChatGPT-NixOS-Workbench.html](ChatGPT-NixOS-Workbench.html) в современном Firefox или Chromium. Это единый автономный HTML: интерфейс, стили, логика и каталог включены в файл. Сетевое подключение для работы мастера не требуется.

## Принцип работы

По умолчанию всё пусто. Мастер ведёт пользователя по этапам от сведений об оборудовании и установке к загрузчику, Nix/Flakes/Home Manager, окружению, драйверам, службам, программам, Gaming, разработке и обслуживанию.

У каждого варианта есть объяснение, сценарии применения, плюсы, ограничения, альтернативы и справка по терминам. Непонятные опции не включаются автоматически.

**Workbench ничего не устанавливает и не применяет к компьютеру.** Он не размечает диски, не запускает `nixos-rebuild`, не удаляет поколения и не выполняет очистку Nix Store. Результат экспорта — черновик, требующий проверки под конкретное оборудование и выбранную версию NixOS.

## Текущий прототип

- 12 этапов и 129 вариантов/инструментов.
- Все исходные выборы пустые.
- Пользовательские пресеты, импорт и экспорт JSON, сохранение раскладки.
- Перетаскивание этапов, групп и вариантов.
- Справка `?` с объяснениями терминов и ссылками на документацию.
- Раздельные настройки лимита boot menu, хранения поколений и garbage collection.
- Ограниченный генератор Nix-черновика с явной маркировкой неподдержанных мэппингов.

## Разработка

Полная многфайловая структура проекта находится в рабочем дереве разработчика. Ключевые файлы:

- `wizard/catalog.json` — каталог решений;
- `wizard/app.js` — логика визарда и генератор черновика;
- `wizard/styles.css` — интерфейс;
- `wizard/index.html` — версия для разработки;
- `tools/build_single_html.py` — сборка автономного HTML;
- `tools/validate_catalog.py` — проверка повторов, примеров и синхронизации каталога;
- `tools/test_generator_runtime.cjs` — smoke-test генератора.

Проверки:

```bash
python3 tools/build_single_html.py
python3 tools/validate_catalog.py
node --check wizard/app.js
node tools/test_generator_runtime.cjs
```

Для реальной сборки конфигурации на машине с Nix дополнительно требуется `nix flake check`. Он не запускался в среде подготовки.

## Ограничения

Каталог курируемый, а не полный дамп NixOS options и Nixpkgs. Не все приложения имеют декларативные настройки; покрытие маркируется отдельно. Генератор поддерживает только часть пунктов и пока не создаёт готовую установочную систему, disk layout, hardware-configuration или секреты.

## Безопасность

Репозиторий сейчас **публичный**. Не публикуйте в нём секреты, SSH/LUKS-ключи, пароли или экспорт профиля с личными данными об устройстве. Для конфигураций конкретных машин используйте отдельный приватный репозиторий.
