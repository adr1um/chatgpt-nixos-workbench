# ChatGPT NixOS Workbench

**Пошаговый мастер проектирования NixOS-конфигурации.** Не готовый дистрибутив, не «магический оптимизатор» и не набор заранее включённых программ.

## Главная идея

По умолчанию профиль пустой. Пользователь проходит этапы, отвечает на вопросы и сам выбирает каждую функцию, среду и программу. В справке объясняется, что означает каждый термин, зачем нужна опция, какие есть альтернативы, плюсы, минусы и риски. Только после проверки ответов Workbench формирует черновики конфигурационных файлов.

**Workbench ничего не устанавливает и ничего не применяет к компьютеру.** Он не форматирует диски, не создаёт разделы, не сохраняет пароли, не запускает `nixos-rebuild` и не выполняет очистку поколений. Все такие действия остаются за пользователем и требуют отдельного осознанного подтверждения.

## Быстрый старт

1. Распакуй проект в любую папку.
2. Открой `wizard/index.html` в Firefox или другом современном браузере.
3. Иди по этапам слева направо. Неизвестные параметры не угадывай.
4. Нажми **Сохранить**, чтобы сохранить рабочий профиль в этом браузере.
5. Нажми **Экспорт профиля**, чтобы получить JSON, который можно перенести на другой компьютер или приложить к следующему разговору.
6. В конце можно скачать Nix-черновик. Он намеренно помечен как неполный: перед установкой нужно проверить hardware, диски, учётную запись, загрузчик и версии опций.

Проверить целостность каталога и генератор:

```bash
python3 tools/validate_catalog.py
node --check wizard/app.js
node tools/test_generator_runtime.cjs
```

Для локального запуска через веб-сервер (необязательно):

```bash
cd wizard
python3 -m http.server 8000
```

Затем открой `http://localhost:8000`.

## Что уже есть в прототипе

- 12 этапов мастера.
- 129 опций и программ в стартовом каталоге.
- Пустое состояние по умолчанию: ни одна программа, оболочка, среда рабочего стола или сервис не выбраны.
- Интерактивные чекбоксы, одиночный выбор, поля и селекторы.
- Справка `?` у вариантов и полей; словарные значки у важных терминов внутри справки.
- Для вариантов указаны описание, назначение, плюсы, минусы, минимум три альтернативы и два примера использования, качественная оценка распространённости и предупреждения. Популярность является редакционной оценкой, не статистикой.
- Демонстрационные пресеты; они не применяются автоматически. Можно добавить пресет поверх текущих выборов или явно заменить ими текущие выборы.
- Сохранение/загрузка рабочего профиля, импорт и экспорт JSON; пользовательские пресеты и раскладка входят в переносимый профиль.
- Пользовательские пресеты.
- Добавление собственных приложений/функций.
- Перетаскивание этапов, групп и вариантов; стрелки вверх/вниз доступны как альтернатива drag-and-drop. Свободное перемещение каждой отдельной кнопки пока не входит в прототип: перемещаются смысловые блоки, чтобы не ломать последовательный сценарий мастера.
- Сохранение раскладки в браузере и включение её в экспорт профиля.
- Отдельные настройки для меню загрузки, хранения generations и Nix Garbage Collection.
- Экспорт ограниченного Nix-черновика для части наиболее распространённых выборов.

## Что пока НЕ реализовано

Это локальный интерактивный прототип v0.3 и спецификация архитектуры, а не финальный установочный конфиг и не полная реализация обещанной «обёртки над всей NixOS».

- Каталог пока курируемый, не полный: 129 записей — стартовый набор, не вся база NixOS options и Nixpkgs.
- Не все настройки каждого приложения доступны через Nix. Покрытие конкретной программы будет помечаться как Full / Partial / Install-only.
- Генератор Nix покрывает только часть опций. Он не создаёт безопасную разметку диска, `hardware-configuration.nix`, секреты, пользовательские пароли или готовую установочную систему.
- Для полноценного генератора нужны проверки на выбранной ветке NixOS и команда `nix flake check` на машине с Nix.
- GitHub-синхронизация сейчас документирована, но локальный интерфейс ещё не выполняет push/pull сам.

## Структура

- `wizard/` — локальный интерфейс, JS, CSS и каталог функций.
- `docs/` — инструкция, архитектура, концепции, сценарии, безопасность и рабочий процесс помощника.
- `modules/` — точки входа для будущих NixOS и Home Manager модулей.
- `hosts/` — аппаратно-зависимые профили конкретных машин.
- `profiles/` — пользовательские JSON-профили.
- `flake-templates/` — стартовые примеры Flakes.
- `generated/` — место для результатов генерации, не для секретов.
- `tools/` — проверки каталога и генератора.

## Правила проекта

Перед изменениями читай [AGENTS.md](AGENTS.md), [архитектуру](docs/architecture.md) и [рабочий процесс помощника](docs/assistant-workflow.md). Главные принципы: пусто по умолчанию, никаких неявных установок, никаких автоматических опасных действий, маленькие точечные изменения и честная маркировка неполного покрытия.
